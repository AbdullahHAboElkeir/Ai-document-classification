# AI Document Classification & Routing System

An AI-powered system that classifies incoming documents into predefined categories and recommends the appropriate department for routing.

## Project Overview

This project aims to automate document classification using Natural Language Processing (NLP) and Machine Learning.

## Planned Features

- Dataset preparation and text preprocessing
- TF-IDF baseline with classical ML models
- Advanced text classification using Hugging Face Transformers
- Model evaluation using Precision, Recall, and F1-score
- Error analysis and experiment tracking with MLflow
- Document classification and routing recommendation
- Model inference and deployment

## Tech Stack

- Python
- Pandas & NumPy
- Scikit-learn
- Hugging Face Transformers
- MLflow
- Streamlit / FastAPI
